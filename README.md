# Spanish (Español) — a jobslop plugin

jobslop in Spanish: every screen, plus Spanish job titles when you search in Spain and Latin America.

## What it adds

- **Language:** Español — the whole screen, plus local job titles when searching in ES, MX, AR, CL, CO

## Install

It comes with jobslop — switch it on in **Settings → Plugins**.

To get a newer version before jobslop's next release: **Settings → Plugins → Check for plugin updates**,
or paste `https://github.com/JobSlop/jobslop-plugin-lang-es` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
